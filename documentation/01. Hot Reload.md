# Hot Reload в likablog.ru

## Проблема

При запуске `php artisan serve --host=0.0.0.0 --port=8000` на основном компьютере и `npm run dev` на основном компьютере, второй разработчик не видит обновления SCSS/JS (hot reload) на `http://ваш_IP:8000`.

## Причина

1. Laravel подключает CSS/JS через `@vite`.
2. В режиме `dev`, `@vite` пытается загрузить ресурсы с Vite-сервера (обычно `http://localhost:5173`).
3. Если Vite запущен с `--host`, но не настроен на HMR с указанием IP, браузер второго разработчика получает адрес `http://[::]:5173` (IPv6).
4. Запрос с `http://ваш_IP:8000` на `http://[::]:5173` блокируется политикой CORS.

## Решение

### 1. Настройка Vite

Откройте `vite.config.js` и убедитесь, что:

```js
// vite.config.js
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.js'],
            refresh: true,
        }),
    ],
    server: {
        host: '0.0.0.0',
        port: 5173,
        hmr: {
            host: 'ваш_IP_в_локальной_сети', // Например, '192.168.0.159'
        },
    },
});
```

### 2. Запуск

1. Убедитесь, что порт 5173 разрешён в брандмауэре Windows.
2. Запустите Vite:
    ```bash
    npm run dev -- --host
    ```
3. Запустите Laravel:
    ```bash
    php artisan serve --host=0.0.0.0 --port=8000
    ```

### 3. Работа с другим разработчиком

1. Второй разработчик заходит на `http://ваш_IP:8000`. 
2. Его браузер автоматически подключится к `http://ваш_IP:5173` для получения SCSS/JS. 
3. При изменении SCSS/JS, изменения мгновенно отображаются у второго разработчика.
