# 📧 Документация: Система смены email пользователя

## 🎯 Обзор

Система обеспечивает безопасную двухэтапную смену email адреса пользователя с подтверждением как нового, так и старого email.

## 🔄 Процесс смены email

### 1. Инициация процесса
**Маршрут:** `POST /user/email/change`

Пользователь вводит новый email:
```php
$service->initiate($user, $newEmail);
```

**Что происходит:**
- Проверяются cooldown'ы (пароль, email, предыдущие запросы)
- Создается запись `UserEmailUpdate` с токеном
- Отправляется письмо на **новый email** для верификации

### 2. Верификация нового email
**Маршрут:** `GET /user/email/verify/{token}`

Пользователь переходит по ссылке из письма:
```php
$service->verify($token);
```

**Что происходит:**
- Токен проверяется на валидность и срок действия
- Новый email помечается как верифицированный
- Генерируется **новый токен** для следующего шага
- Отправляется письмо на **старый email** для подтверждения

### 3. Подтверждение старого email
**Маршрут:** `GET /user/email/confirm/{token}`

Пользователь переходит по ссылке из второго письма:
```php
$service->confirm($token);
```

**Что происходит:**
- Текущий email сохраняется в `UserEmailHistory`
- Email пользователя обновляется на новый
- Запись `UserEmailUpdate` удаляется
- Пользователь получает уведомление об успехе

## ⚙️ Дополнительные функции

### Повторная отправка письма
**Маршрут:** `POST /user/email/resend`

Определяет какое письмо отправить:
- Если новый email не верифицирован → письмо на новый email
- Если новый email верифицирован → письмо на старый email

### Отмена процесса
**Маршрут:** `POST /user/email/cancel`

Удаляет pending-запрос и устанавливает cooldown.

## 🛡️ Меры безопасности

### Cooldown'ы (настраиваются в config/user.php)
```php
'email_password_cooldown' => 86400,    // 24 часа после смены пароля
'email_change_cooldown' => 2592000,    // 30 дней после смены email  
'email_request_cooldown' => 3600,      // 1 час после отмены запроса
```

### Валидация токенов
- Токены имеют ограниченное время жизни
- Одноразовое использование
- Проверка на существование и валидность

### Защита роутов
- Только для аутентифицированных пользователей
- Только для пользователей с подтвержденным email
- Rate limiting: 5 запросов в минуту

## 📊 Модели данных

### UserEmailUpdate
Хранит pending-запросы на смену email:
- `user_id` - связь с пользователем
- `email` - новый email адрес
- `token` - верификационный токен
- `verified_at` - когда новый email подтвержден
- `expires_at` - срок действия токена

### UserEmailHistory
Архив предыдущих email адресов:
- `user_id` - связь с пользователем
- `email` - старый email
- `active_from` - когда начал использоваться
- `active_to` - когда был заменен

## 📨 Система писем

### UserEmailChangeVerifyNew
**Отправляется на новый email:**
- Подтверждение владения новым email
- Содержит токен для верификации

### UserEmailChangeConfirmOld
**Отправляется на старый email:**
- Подтверждение намерения сменить email
- Содержит финальный токен подтверждения

## 🚀 Использование в коде

### Контроллер
```php
$emailChangeController->initiate($request, $service);
$emailChangeController->verify($token, $service);
$emailChangeController->confirm($token, $service);
```

### Сервис
```php
$emailChangeService->initiate($user, $email);
$emailChangeService->verify($token);
$emailChangeService->confirm($token);
$emailChangeService->resend($user);
$emailChangeService->cancel($user);
```

## 🔍 Обработка ошибок

Система генерирует понятные сообщения об ошибках:
- Cooldown активен
- Токен не найден или просрочен
- Уже есть активный запрос

Все ошибки локализованы (ru/en) и безопасны для показа пользователю.
