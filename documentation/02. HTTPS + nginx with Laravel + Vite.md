# Nginx/HTTPS: историческая документация

> **Актуальная инструкция:** [`docs/local-development.md`](../docs/local-development.md).
>
> Этот файл сохранён только как исторический материал. Проект теперь использует **Bun + Vite 8**, поэтому команды `npm`, старые Vite entry points и старый пример `vite.config.js` ниже не являются актуальными и не должны использоваться для текущего dev bootstrap.

Для стандартной локальной разработки Nginx и HTTPS не требуются: используйте `php artisan serve` + `bun run dev`.

HTTPS/LAN-профиль описан в актуальной инструкции и требует локально сгенерированного `mkcert` сертификата; приватный ключ не хранится в репозитории.
